# Electronic Voting System

This project is an **Electronic Voting System** implemented in Java and built with **Maven**. The application is designed to provide a simple, reliable, and efficient solution for electronic voting processes.

## Features

- User-friendly interface built with JavaFX.
- Secure and efficient electronic voting functionalities.
- Uses Maven for dependency management and build automation.

## Technologies Used

- **Java**: Core programming language.
- **JavaFX**: For the graphical user interface.
- **Maven**: For project management and build automation.
- **SQL Database**: For storing voting data securely.

## Prerequisites

Before running the project, ensure you have the following installed:

- Java 15 or higher
- Maven 3.9.9 or higher
- PostgreSQL Database

### Build the Project

Run the following Maven command to compile the project:

```bash
mvn clean install
```

### Run the Application

To launch the application:

```bash
mvn javafx:run
```

## Database Configuration

The database dump file for **PostgreSQL** is included in the `Database` directory.
